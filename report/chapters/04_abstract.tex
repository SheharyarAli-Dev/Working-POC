\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
AI-assisted software changes can alter dependencies, application code and infrastructure, and passing tests do not show that an existing security boundary still holds. ASENT (Agent Sentinel) is a local security-assurance gate that combines evidence from three modules into one decision of \texttt{ACCEPT}, \texttt{REVIEW} or \texttt{BLOCK}. CAVR checks dependency and capability evidence, SATRA-RV evaluates application-code changes against trusted tests and a sandboxed repair workflow, and SABLE checks whether a registered IAM/S3 obligation still holds on the successor of a protected Terraform resource after a refactor. SABLE's deterministic security decision path does not rely on an LLM. On the verified combined snapshot \texttt{665b224}, Core CI, SATRA CI, and SABLE shared-assurance CI succeeded. The Docker-enabled full suite passed 1,427 tests with 26 skipped and one warning; SATRA passed 84 tests with all four required Docker checks run; and the focused SABLE/shared-assurance job passed 46 tests. Frontend build/render checks ran separately. These controlled results do not establish live-cloud behavior or independent detection rates. FYP-2 will complete the agreed comparative evaluation, broaden validation where the research question supports it, and continue integrated testing.
