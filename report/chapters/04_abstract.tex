\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
AI-assisted software changes can affect dependency integrity, application behavior, and infrastructure security before a reviewer can confidently trust or merge them. Syntax checks and ordinary tests do not by themselves establish that a change preserves an existing security boundary. ASENT (Agent Sentinel) is an integrated security-assurance gateway intended to combine evidence from CAVR, SATRA-RV, and SABLE. At the FYP-1 mid-assessment stage, the strongest implementation evidence in this report concerns SABLE and its shared evidence/final-gate path. SABLE parses a bounded subset of Terraform/HCL, identifies a likely successor to a protected logical resource using structural evidence, and evaluates a registered IAM/S3 obligation. It returns \texttt{PRESERVED}, \texttt{REGRESSED}, or \texttt{UNKNOWN}. The focused local worktree selection reported here passed 27 tests with 10 deselected, including four parameterized shared-gate cases; an earlier focused CI run passed 44 tests on the published branch commit before the local evaluator correction. The current \texttt{sable} checkout was rehearsed with completed shared-workflow runs showing \texttt{PRESERVED}/\texttt{REVIEW}, \texttt{REGRESSED}/\texttt{BLOCK}, and \texttt{UNKNOWN}/\texttt{REVIEW}; the preserved run received \texttt{REVIEW} because SATRA was \texttt{INCONCLUSIVE}. An earlier retained application run also shows SABLE \texttt{REGRESSED} and overall \texttt{BLOCK}, with SATRA \texttt{INCONCLUSIVE}. These results are controlled early validation, not full Terraform or AWS semantics, live-cloud behavior, comparative research results, or complete system readiness. The remaining research experiments and team report evidence are identified separately.
