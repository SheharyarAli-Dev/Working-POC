\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
AI-assisted software changes can alter dependencies, application code and infrastructure, and passing tests do not show that an existing security boundary still holds. ASENT (Agent Sentinel) is a local security-assurance gate that combines evidence from three modules into one decision of \texttt{ACCEPT}, \texttt{REVIEW} or \texttt{BLOCK}. CAVR verifies a real \texttt{pip install} request against the project policy, the downloaded wheel's SHA-256, OSV advisories and a capability contract taken from the project's own code. SATRA-RV judges an AI-generated application-code patch with trusted security tests, validated adaptive tests and sandboxed repair verification. SABLE checks whether a registered IAM/S3 obligation still holds on the successor of a protected Terraform resource after a refactor. An unknown result in any module goes to review. At the mid stage, CAVR passes 1254 tests in CI and gave the expected verdict on six recorded real requests; SATRA-RV's test report records 75 of 75 unit tests passing on its branch; and SABLE's focused selection passed 27 tests with 10 deselected. These are controlled early results, not measured detection rates. FYP-2 will add sandbox execution and verified repair to CAVR, evaluate each module against baselines, and validate the three modules together in the integrated workflow.
